## artbutler-php-sdk

Deprecated PHP GraphQL client for abnext-laravel's `/graphql`. Its only consumer is abnext-websites, which still uses its DTOs and the translations client; viewer data comes over REST now. Prefer extending abnext-laravel's viewer REST payload over adding SDK features. Work on `develop` — `master` stopped in 2022. A change reaches websites only after a new `v0.3.x` tag and `composer update derave-software/artbutler-php-sdk` there. Cross-repo map: the workspace-root `AGENTS.md` in abnext-workspace.
